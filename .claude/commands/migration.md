
Create and apply an Alembic migration for the Integra project.

Follow ALL constraints from CLAUDE.md:

- Never use CREATE TABLE or ALTER TABLE in startup code — always use Alembic
- Never hard-delete records — use is_active = False
- Always keep clinic_id on every new table

Steps to execute:

1. Make sure all SQLModel model changes are saved
2. Generate the migration:
   ```bash
   docker compose exec web alembic revision --autogenerate -m "$ARGUMENTS"
   ```
3. Review the generated migration file in `migrations/versions/` — confirm it looks correct before applying
4. Apply the migration:
   ```bash
   docker compose exec web alembic upgrade head
   ```
5. Confirm the migration was applied successfully with:
   ```bash
   docker compose exec web alembic current
   ```

If the autogenerated migration is empty or incorrect, investigate why (missing model import in `env.py`, model not registered, etc.) before proceeding.

Migration description: $ARGUMENTS
